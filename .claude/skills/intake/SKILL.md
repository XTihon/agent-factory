---
name: intake
description: Разбирает материалы из inbox/<slug> в план с измеримыми критериями приёмки и подбором исполнителей. Для начала нового проекта.
allowed-tools: Read, Write, Glob, Grep
---

Прочитай все файлы в inbox/$ARGUMENTS/. Создай state/$ARGUMENTS/brief.md:

1. Цель проекта — один абзац.
2. Явно: что входит в объём, что нет.
3. Нумерованный список задач.
4. Для каждой задачи — критерий приёмки, проверяемый объективно и одинаково
   строго для любой области: код — по выводу команды или тестов, текст — по
   наличию нужных разделов и точности фактов, данные — по совпадению со
   схемой или пересчётом, всё остальное — по конкретному чек-листу. Не
   расплывчатое «сделать хорошо».
5. Исполнитель на задачу: сначала ищи среди .claude/agents/*.md по description,
   помечай задачи без подходящего агента флагом «нужен новый агент».
6. Если несколько задач, вероятно, будут выполняться параллельно — отметь,
   какие файлы/пути каждая из них затронет, чтобы оркестратор мог проверить
   отсутствие пересечений перед распараллеливанием (worktree-изоляции в этой
   версии нет).

Создай state/$ARGUMENTS/status.md со всеми задачами в статусе todo и счётчиком
попыток 0.
