# ТЗ: FizzBuzz-утилита (тестовый прогон системы)

Цель: проверить весь цикл agent-factory (intake → delegate → verify → git
commit → report) на маленькой, полностью объективно проверяемой задаче.

## Задача 1 — fizzbuzz.py

Создать файл `fizzbuzz.py`:
- функция `fizzbuzz(n: int) -> str`: возвращает `"Fizz"` для чисел кратных 3,
  `"Buzz"` для кратных 5, `"FizzBuzz"` для кратных и 3, и 5, иначе `str(n)`.
- при запуске файла как скрипта (`python fizzbuzz.py`) печатает результат
  `fizzbuzz(n)` для n от 1 до 100 включительно, по одному значению в строке.

**Критерий приёмки:**
- `python fizzbuzz.py` печатает ровно 100 строк.
- строка 7 = `7`
- строка 9 = `Fizz`
- строка 10 = `Buzz`
- строка 15 = `FizzBuzz`
- строка 100 = `Buzz`

## Задача 2 — test_fizzbuzz.py

Юнит-тесты (pytest) на функцию `fizzbuzz()` из задачи 1: проверить минимум
случаи n=1 (обычное число), n=3 (Fizz), n=5 (Buzz), n=15 (FizzBuzz).

**Критерий приёмки:**
- `python -m pytest test_fizzbuzz.py` завершается с exit code 0.
- в файле минимум 4 отдельных assert/тест-кейса на перечисленные случаи.

## Вне объёма

Никакого CLI с аргументами, никакого веб-интерфейса, никаких зависимостей
кроме stdlib и pytest. Это демонстрационный прогон — делать строго по
критерию, не больше.
