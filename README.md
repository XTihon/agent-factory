# agent-factory

Система, которая доводит проекты до готовности силами агентов почти без
ручного вмешательства. Годится для чего угодно — код, тексты, данные,
исследования.

## Как пользоваться

1. Положи материалы своего проекта (ТЗ, файлы, данные) в новую папку
   `inbox/<slug>/` — `<slug>` придумай сам, короткое имя проекта.
2. Запусти Claude Code в этой папке (`agent-factory`):
   ```
   claude
   ```
   **Важно:** если это первый запуск сразу после того, как система была
   создана — перезапусти `claude`, чтобы он подхватил новых агентов и
   скиллы. Без перезапуска `/start-project` может не распознаться.
3. Введи:
   ```
   /start-project <slug>
   ```
   Ведущий агент разберёт материалы, покажет план задач и исполнителей,
   после твоего согласия начнёт цикл: делегирование → независимая проверка
   → доработка при провале → следующая задача.
4. Чтобы цикл шёл сам, без подталкивания на каждом шаге, включи:
   ```
   /goal все задачи проекта <slug> в state/<slug>/status.md имеют статус verified или needs-human; останови после 40 хода
   ```
   Ограничение по ходам обязательно — чтобы цикл не завис навсегда на одной
   проблемной задаче.
5. Результат появится в `output/<slug>/` вместе с `report.md`. Задачи, которые
   не прошли проверку за 4 попытки, попадут в `status.md` как `needs-human` —
   их нужно решить самому.

## Диалог доверия (workspace trust)

При первом запуске Claude Code в новой папке он может спросить, доверяешь ли
ты этой директории — без подтверждения хуки в `.claude/hooks/` не сработают,
и защита ведущего агента от «специализированной работы своими руками» не
будет применяться. Подтверди доверие этой папке.

## Прозрачность и контроль

- Каждая проверенная (`verified`) задача — отдельный git-коммит. `git log` —
  полная история проекта, `git diff` — что именно изменила задача.
- Если что-то пошло не так — есть откат через git, без необходимости
  восстанавливать состояние вручную.
- `/usage` в Claude Code — расход токенов по скиллам и агентам за сессию.
- Перед тем как отпускать систему на большой проект без присмотра, прогони
  её на одной небольшой задаче и посмотри на качество и расход токенов.

## Ограничения

Хуки в `.claude/hooks/` — эвристики по regex, не песочница: снижают риск
случайного нарушения роли, но не заменяют ревью на действительно
чувствительных проектах.
